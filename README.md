# Blueline Urban Projects — Demo
Production-oriented static prototype built from researched, sourced material.

- `index.html` — home
- `about.html` — company
- `capabilities.html` — capabilities
- `projects.html` — searchable project library
- `project.html?slug=...` — reusable project case study
- `track-record.html` — proof/track record
- `insights.html` — intentionally lightweight
- `start-a-project.html` — project intake
- `contact.html` — contact
- `assets/` — project imagery

All facts are sourced from Blueline's historical project archive or clearly marked as requiring confirmation.
